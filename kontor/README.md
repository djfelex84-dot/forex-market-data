# Kontor

Учёт склада, счетов, закупок, расходов, банка и НДС для небольших эстонских фирм.
Программа работает на эстонском, английском и русском. У каждой фирмы свой вход и свои данные.

- Склад: товары с размером, цветом, материалом, фото, EAN; остатки и себестоимость.
- Счета клиентам на эстонском или английском, с виитенумбером; 0% для фирм ЕС, экспорт.
- Закупки и расходы, в том числе с обратным начислением НДС (товары и услуги из ЕС).
- Загрузка счёта поставщика (PDF или фото): программа сама читает данные (нужен ключ Anthropic API).
- Выписка из банка (CSV или XML camt.053): программа сама связывает платежи со счетами.
- НДС за месяц: суммы для KMD, список для отчёта VD, партнёры для KMD INF.
- Выгрузка журнала месяца в CSV и полная копия данных.
- Ставится на телефон как приложение (иконка на главном экране).

Данные хранятся в одной базе SQLite в папке `data/`. Каждые 6 часов программа проверяет,
есть ли копия базы за сегодня, и, если нет, делает её в `data/backups/`. Хранятся последние 14 копий.

## Установка на сервер (Hetzner, Ubuntu)

Нужны: сервер с Docker, домен и 15 минут. Все команды выполняются на сервере по SSH.

### 1. Поддомен

В панели, где управляете доменом (DNS), добавьте запись:

| Тип | Имя | Значение |
|---|---|---|
| A | `kontor` | IP-адрес вашего сервера |

Через несколько минут адрес `kontor.вашдомен.ee` будет вести на сервер.

### 2. Docker

Проверьте: `docker --version` и `docker compose version`. Если Docker не установлен:

```bash
curl -fsSL https://get.docker.com | sh
```

### 3. Программа

```bash
cd /opt
git clone https://github.com/djfelex84-dot/forex-market-data.git kontor-src
cp -r kontor-src/kontor /opt/kontor
cd /opt/kontor
cp .env.example .env
nano .env        # впишите свой e-mail, пароль администратора и название фирмы
docker compose up -d --build
docker compose logs --tail 20
```

В логе должно быть `Created administrator …` и `Kontor listening on :3000`.
Программа теперь работает на сервере по адресу `127.0.0.1:3080`. Снаружи она пока не видна, это нормально.

После первого входа пароль администратора из `.env` больше не используется. Смените его в программе
(«Настройки» → «Мой вход») и удалите его из `.env`.

### 4. Адрес с https

**Если на сервере уже стоит nginx** (например, для сайта магазина), создайте файл
`/etc/nginx/sites-available/kontor`:

```nginx
server {
    server_name kontor.вашдомен.ee;
    client_max_body_size 25m;

    location / {
        proxy_pass http://127.0.0.1:3080;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header X-Forwarded-For $remote_addr;
        # Живые обновления между телефоном и компьютером
        proxy_buffering off;
        proxy_read_timeout 1h;
    }
}
```

```bash
ln -s /etc/nginx/sites-available/kontor /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx
apt install -y certbot python3-certbot-nginx   # если certbot ещё не стоит
certbot --nginx -d kontor.вашдомен.ee
```

**Если сайт работает через панель** (Plesk, CloudPanel, cPanel и т. п.), создайте в панели поддомен
с обратным прокси (reverse proxy) на `http://127.0.0.1:3080` и включите сертификат Let's Encrypt.
Если в панели есть настройка буферизации прокси, выключите её, чтобы изменения сразу появлялись на всех устройствах.

Откройте `https://kontor.вашдомен.ee` и войдите.

### 5. Телефон

Откройте адрес в браузере телефона:
- iPhone (Safari): «Поделиться», затем «На экран Домой».
- Android (Chrome): «⋮», затем «Добавить на главный экран».

## Друзья и другие фирмы

«Настройки» → «Администрирование: фирмы» → «Новая фирма». Укажите название, e-mail и пароль владельца
и передайте ему адрес программы. Каждая фирма видит только свои данные.
Владелец фирмы может сам добавить сотрудника (например, бухгалтера) в разделе «Пользователи фирмы».

## Распознавание счетов

Нужен ключ Anthropic API: зарегистрируйтесь на console.anthropic.com, пополните баланс и создайте ключ.
Вставьте его в «Настройки» → «Распознавание счетов». Ключ хранится на сервере и в браузер не передаётся.
Можно указать общий ключ для всех фирм в `.env` (`ANTHROPIC_API_KEY`).
Модель задаётся в `.env` (`AI_MODEL`, по умолчанию `claude-opus-5`).

## Обновление

```bash
cd /opt/kontor-src && git pull
cp -r /opt/kontor-src/kontor/. /opt/kontor/
cd /opt/kontor && docker compose up -d --build
```

Папка `data/` и файл `.env` при обновлении не затрагиваются.

## Резервные копии

Всё хранится в `/opt/kontor/data`: база `kontor.db`, загруженные файлы `files/` и ежедневные копии `backups/`.
Время от времени копируйте эту папку на другой компьютер или в облако, например:

```bash
rsync -a root@сервер:/opt/kontor/data/ ./kontor-backup/
```

## Запуск без Docker (для проверки)

Нужен Node.js 22.13 или новее.

```bash
npm install
ADMIN_EMAIL=you@example.com ADMIN_PASSWORD=secret123 npm start
```

Программа откроется на http://localhost:3000.
